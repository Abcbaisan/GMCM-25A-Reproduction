# 论文项目约束

复制整个 _template 到根 papers/<paper_id>/，读取系统根规则、core/AGENTS.md、domains/machine_learning/AGENTS.md、domain.yaml 与本目录 README。
保留 code/、notes/、reproduction/ 工作方式；实验保存环境、数据划分、随机种子、命令、参数、日志与真实结果。论文报告与实测分开。

知识治理、Capture/Curator/Mentor 角色均继承 Core，不在论文项目重新定义。不得修改其他论文实验和原始数据。
